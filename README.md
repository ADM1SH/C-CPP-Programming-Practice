# C & C++ Programming Practice

## Description
A collection of practice scripts and small programs written in C and C++. This repository serves as a sandbox for learning syntax, data types, and core programming logic.

## Contents
- `class1.cpp`: Basic C++ class structure and object-oriented programming intro.
- `test.c`, `test.cpp`: Generic test scripts for validating logic.
- `yes.cpp`, `yes copy.cpp`: Simple output repetition logic.
- `test4.cpp`, `test2.cpp`: Additional practice files for various concepts.
